# 🏡 House Price Prediction

A Machine Learning web application that predicts house prices based on housing features. The project includes data analysis, model training, and an interactive Gradio interface for real-time predictions.

---

## 🚀 Features

- 📊 Exploratory Data Analysis (EDA)
- 🤖 Machine Learning model training
- 🏆 Best model saved as `best_model.pkl`
- 🌐 Interactive Gradio web application
- 📈 Real-time house price prediction

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Gradio
- Matplotlib
- Joblib
